# [andreferraz.com](https://andreferraz.com)

Personal site. Currently a work-in-progress placeholder while the site is
rebuilt as a personal digital garden.

## Development

A single static HTML file with inline CSS. No build step.

**Preview:**

```sh
python3 -m http.server -d src
```

Then open [http://localhost:8000](http://localhost:8000).
